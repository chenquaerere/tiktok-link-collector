# TikTok 作品链接采集器 · TikTok Link Collector

> 当前版本：**v1.1.0**（2026-09-26）｜ [更新日志 CHANGELOG](CHANGELOG.md)

批量采集自己 TikTok 账号作品链接的 Windows 桌面工具，**并支持从群聊 / 好友对话框采集被分享的作品链接**。

- **作品采集**：多账号 → 批量访问主页 → 抓取每个账号最新的 N 条作品链接 → 自动去重 → 一键复制 → 导出。
- **聊天采集**：进入消息页 → 选择群聊 / 好友 → 采集该对话框内分享的作品链接（**最新在最上**）。

> 这是「链接采集工具」，**不是**视频下载工具——只获取作品页面 URL，不下载视频。

---

## 核心原则

**抓取最新 N 条，不过滤日期。** 按主页时间倒序，直接取每个账号最新的 N 条作品链接（N = 每账号采集数量），不管发布于今天、昨天还是更早。发布时间（`createTime`）会尽力解析并记录到结果里，但**不用于过滤**。

**聊天采集按「最下面最新」取值。** 聊天记录自上而下按时间排列，程序按窗口内的垂直位置从下往上取，取满你填的数量为止；不够则向上滚动加载更早的历史。

**替换式记录。** 同一个账号 / 同一个会话多次采集，结果按「最后一次运行」替换，不会越采越堆。

**严格串行。** 一个账号（或一个会话）完整采集并保存后才进入下一个；单个失败不阻断整体。

**不绕过任何验证。** 程序只检测登录失效 / CAPTCHA / 安全验证并提示，绝不尝试破解。

## 功能

### 作品链接采集

- **账号池**：长期保存大量账号主页链接，支持批量粘贴 / 导入 TXT·CSV·XLSX（部分格式错误不影响其余账号）
- **采集**：抓取每个账号最新的 N 条作品（不过滤日期）、每账号数量独立设置、严格串行访问、实时进度、暂停/继续/停止、失败重试
- **去重**：以 `video_id` 为唯一键，多次采集按最后一次结果替换
- **复制**：复制全部 / 按账号分组 / 纯 URL 模式 / 链接窗口框选复制
- **导出**：TXT / CSV / XLSX（Excel 含「作品链接」+「账号统计」两个 Sheet）
- **历史**：任务记录、账号明细、可回溯
- **每日链接日志**：每天采集到的链接自动归档到 `links_log/YYYYMMDD.txt`

### 聊天链接采集（v1.1.0 新增，独立板块）

- **免关键词浏览**：直接拉取消息页全部会话（群聊 + 好友混排），支持关键词实时过滤 + 类型筛选（全部/好友/群聊）
- **整行点选目标**：点一下整行即选中（选中行高亮），**双击直接开始采集**
- **目标唯一绑定 + 二次校验**：以 `data-conversation-id` 为稳定标识，采集前再次校验聊天头部与所选目标一致，不一致立即停止（绝不采错会话）
- **一键登录消息功能**：弹出浏览器登录一次，登录态按账号保存，之后免登录
- **最近使用目标**：记住最近 5 个目标，点击即选中并同步高亮左侧列表
- **彩色 emoji**：群名 `🔥⚡️` 等彩色显示（Pillow 渲染，非系统黑白字形）
- **链接操作**：一键复制（一行一条，可直接粘贴到下游工具）、导出 TXT、清空
- **可视化开关**：勾选「显示浏览器窗口」可亲眼看到程序进入对话框并滚动加载
- **真实停止**：点「停止」后当前这一轮读完即退出，已采到的链接保留

## 环境要求

- Windows 10/11
- 需要能正常访问 TikTok 的网络环境（自备，程序不内置任何代理）
- 聊天采集需要先在程序内完成一次「登录账号」（消息页需要登录态）

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 安装浏览器内核（首次）

```bash
playwright install chromium
```

### 3. 启动

```bash
python main.py
```

### 4. 打包成 EXE（可选）

```bash
pip install pyinstaller
python build.py
# 产物：dist/TikTokLinkCollector/TikTokLinkCollector.exe（整个目录可复制到任意位置）
```

## 使用说明

### 添加账号

进入「账号管理」页：

- **单个添加**：输入主页链接（`https://www.tiktok.com/@username`）或 `@用户名`，回车即可
- **批量导入**：点击「批量导入」，粘贴多行链接，或从 TXT/CSV/XLSX 文件读取。20 个里错 2 个不影响其余 18 个
- 每个账号可单独设置「采集数量」

### 登录 / 验证

程序使用浏览器持久化 Session，**首次使用会弹出浏览器窗口**：

1. 在浏览器中手动完成 TikTok 登录
2. 完成可能出现的验证码 / 人机验证
3. 关闭浏览器窗口后继续

> 程序**不会**尝试绕过 CAPTCHA 或安全验证。若某个账号需要重新验证，该账号会被标记为「需人工处理」，**不会**阻断其他账号采集。

### 采集

进入「采集任务」页：

1. 选择记录日期（今天 / 昨天 / 指定日期，仅作归档标签，不过滤作品）
2. 设置每账号采集数量（可单独调、可批量应用）
3. 勾选要采集的账号（默认全选启用账号）
4. 点击「开始采集」

程序按主页时间倒序，为每个账号抓取最新的 N 条作品链接（后台无头模式，不弹窗、不打扰操作）。

### 复制链接

进入「采集结果」页 → 点击「复制全部」，得到纯 URL（每行一条），可直接粘贴到作品回填工具。

### 聊天采集（从群聊 / 好友对话框取链接）

进入「聊天链接采集」页：

1. 顶部选择「采集账号」
2. 首次使用点 **「登录账号」** —— 弹出浏览器登录一次 TikTok，登录态按账号保存，之后免登录
3. 点 **「刷新会话列表」** 拉取该账号的全部会话（约 15~20 秒，期间状态栏会分阶段提示）
4. 在左侧列表**点一下整行**选中目标（群聊 / 好友皆可；选中行会高亮）；也可以点右侧「最近使用」里的历史目标
5. 填写采集数量，点 **「开始采集」**（或**双击该行**直接开始）
6. 采集完成后，链接按「最新 → 最旧」自上而下排列，可一键复制 / 导出 TXT / 清空

> 勾选 **「显示浏览器窗口」** 可以看到程序自动进入对话框、向上滚动加载的完整过程。
> 采集过程中可以点「停止」中断，已采到的链接会保留。

### 导出

「采集结果」或「历史记录」页 → 选择「导出 TXT / CSV / XLSX」。

### 登录失效 / 验证码

- 程序检测到登录失效、CAPTCHA、安全验证时，**暂停当前账号**并提示
- 处理完成后可点「继续」恢复未完成账号
- 已采集的数据不会丢失

### 查看日志

- 界面「日志」页
- 或直接查看 `logs/app.log`（按日滚动，保留 30 天）

### 更新程序

内置自动更新（GitHub Releases）：

1. 在「设置 → 更新」填写 GitHub 仓库（`owner/repo`），开启「启动时自动检查更新」。
2. 程序启动后会自动检查；发现新版本时弹出「查看下载」提示，点击跳转下载。
3. 下载新包后覆盖 `TikTokLinkCollector.exe`（或整个目录）即可；数据、日志、链接日志在 `data/`、`logs/`、`links_log/` 独立保存，不受影响。

## 目录结构（运行产物）

```
TikTokLinkCollector/
├── TikTokLinkCollector.exe   # 主程序（打包后）
├── config.json               # 配置文件（首次运行生成）
├── data/                     # 数据库 + 浏览器 Session
├── logs/                     # 运行日志
├── links_log/                # 每日链接日志（YYYYMMDD.txt）
└── exports/                  # 导出文件
```

```
tests/           # 自动化测试（189 用例）
diagnostics/     # 页面结构探针 + 真实采集验证脚本
docs/            # 架构 / 采集架构 / 聊天模块 / 探针报告 / 项目状态
```
