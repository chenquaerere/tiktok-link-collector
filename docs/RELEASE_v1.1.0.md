## v1.1.0 — 新增「聊天链接采集」+ 全项目优化

这是继 v1.0.0 首个正式版之后的一次功能性升级：除原有的「按账号主页采集作品链接」外，**新增一条完全独立的采集链路** —— 进入 TikTok 消息页，从指定的**群聊 / 好友对话框**中采集被分享的作品链接。

---

### 新增：聊天链接采集（独立板块）

- 新增独立导航页「聊天链接采集」，与作品采集**完全隔离**（独立服务、独立数据表、独立采集引擎）
- 流程：选账号 → 一键登录消息功能 → 加载会话列表 → 点选目标 → 采集最新 N 条链接
- **免关键词浏览**：直接拉取消息页全部会话（群聊 + 好友混排），支持关键词实时过滤 + 类型筛选
- **整行点选 + 双击直接采集**：点一下整行即选中（选中行高亮），双击立即开始
- **目标唯一绑定 + 二次校验**：以 `data-conversation-id` 为稳定标识，采集前再次校验聊天头部与所选目标一致，不一致立即停止（绝不采错会话）
- **一键登录消息功能**：弹出浏览器登录一次，登录态按账号保存，之后免登录
- **最近使用目标**：记住最近 5 个目标，点击即选中并同步高亮左侧列表
- **彩色 emoji**：群名 `🔥⚡️` 等彩色显示（Pillow 渲染）
- **链接操作**：一键复制（一行一条，可直接粘贴到下游工具）、导出 TXT、清空
- **可视化开关**：勾选「显示浏览器窗口」可亲眼看到程序进入对话框并滚动加载
- **真实停止**：点「停止」后当前这一轮读完即退出，已采到的链接保留

### 修复：聊天采集取到错误链接

- **现象**：不管选择哪个群聊或好友，采到的都是同一批链接（且全是本人账号的作品）
- **根因**：早期实现整页扫描 `a[href*="/video/"]`，实际抓到的是左侧会话列表预览与页头里的**隐藏链接**，而真正的聊天面板内并不存在这类链接
- **修复**：抽取严格限定在聊天面板作用域内；作品 ID 从 React props 读取，作者经站点接口获取；排序改为按窗口内垂直位置（**最下面那条最新**）
- **验证**：群聊与好友各采 8 条，作者互不相同、各自独立

### 修复：界面「点了没反应」

- 关键动作不再使用模态确认框（弹窗被遮挡时会卡死主界面且无任何日志）：清空链接改为按钮内联二次确认，开始采集直接执行
- 会话行改为**整行可点**（原先只有左侧小圆圈能点，点名称毫无反应）
- 新增线程安全 UI 调度器，修复 worker 线程更新界面导致的「界面永不更新且无报错」

### 修复：其它

- 「停止」按钮改为真实停止（原先是摆设）
- 页面头部占位过大（200px → 60px，8 个页面统一）
- 右下角偶发黑色残块（Toast 改为独立置顶窗口，销毁即消失）
- 进度条实时推进（原全程不动）
- 切换账号自动清空已选目标，防止跨账号目标串号

### 下载与使用

- 下载下方附件 `TikTokLinkCollector_v1.1.0_portable.zip`（约 850 MB，**已内置 Chromium 内核，零依赖**）
- 解压到任意目录，双击 `TikTokLinkCollector.exe` 即可运行（Windows 10/11）
- **升级安装**：直接覆盖旧版目录即可；`data/`、`logs/`、`links_log/`、`config.json` 为用户数据，请保留不动
- 解压密码：无

> 这是「链接采集工具」，**不是**视频下载工具 —— 只获取作品页面 URL，不下载视频。

### 环境要求

- Windows 10/11
- 需要能正常访问 TikTok 的网络环境（自备，程序不内置任何代理）
- 聊天采集需要先在程序内完成一次「登录账号」（消息页需要登录态）
